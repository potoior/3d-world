## 交互

每个场景均提供：

- **地标索引**：左侧「景点」按钮打开，点击条目自动前往。
- **双击聚焦**：双击场景中的建筑/山体，镜头自动推近观察。
- **探索印章**：每到一个地标盖一枚印章，进度保存在本地。
- **场景标记**：点击投影标记查看地标卡片与介绍。
- **自动巡游**：按顺序游览各地标，可暂停/继续。
- **天气**：晴 / 雨 / 雪 切换。
- **摄影模式**：隐藏界面，仅保留场景与退出提示。
- **环境音**：程序化风声、水声与鸟鸣，默认关闭。
- **自动光影**：每 12 秒在日间/黄昏之间切换。
- **留影**：下载当前画面为 PNG。
- **电影感调色**：统一饱和度、对比度、暗角与空气尘埃层。
- **第一人称漫游**：`WASD` 移动 · `Space` 跳跃 · 鼠标环顾 · `Shift` 加速 · `Esc` 退出。
- **快捷键**：`1–9` 切换视角 · `F` 第一人称 · `R` 环绕 · `N` 黄昏 · `T` 巡游 · `L` 自动光影 · `O` 总览 · `G` 留影 · `P` 摄影 · `H` 帮助。

## 本地运行

在项目根目录启动任意静态 HTTP 服务：

```bash
python3 -m http.server 8123
```

打开 <http://localhost:8123>。

> 必须通过 HTTP 访问，直接双击 `index.html` 会因 ES Modules 限制而无法加载。

## 技术

- Three.js r160（本地 vendor）
- ES Modules + import map
- 程序化几何、纹理与动态元素
- 共享交互层：`shared/interactions.js`（索引、巡游、天气、摄影、音景、印章、调色/尘埃）
- 无外部 CDN、无构建依赖

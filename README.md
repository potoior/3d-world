# 3d-world

十六座中国地标的可交互 Three.js 3D 场景。全部资源本地化，无需构建步骤。

## 场景

- **紫禁城**：明清宫城中轴、三大殿、宫门、角楼、御花园，支持第一人称漫游。
- **拙政园**：江南园林水池、远香堂、荷风四面亭、小飞虹、香洲、见山楼与东园。
- **武汉东湖**：真实 OSM 湖岸线、行吟阁、楚天台、听涛、楚城、樱园与环湖绿道。
- **八达岭长城**：山脊城墙、敌楼、垛口、好汉坡与燕山山景。
- **杭州西湖**：苏堤、断桥、雷峰塔、三潭印月、孤山与湖心亭。
- **黄山**：花岗岩峰林、云海、迎客松、光明顶与飞来石。
- **布达拉宫**：红白宫、金顶、石阶、德阳厦与拉萨河谷。
- **桂林漓江**：喀斯特峰林、象鼻山、九马画山、兴坪与竹筏。
- **敦煌 · 鸣沙山月牙泉**：莫高窟九层楼阁、月牙泉、鸣沙山脊与丝路驼队。
- **张家界 · 武陵源**：石英砂岩峰林、天下第一桥、百龙天梯与云海。
- **丽江古城**：纳西民居、水系、石桥、四方街与玉龙雪山。
- **泰山 · 岱宗**：十八盘、南天门、碧霞祠、玉皇顶与日出云海。
- **平遥古城**：灰砖城墙、日昇昌票号、市楼、镖局与十字街巷。
- **华山 · 西岳**：长空栈道、鹞子翻身、北峰/西峰与云海。
- **武夷山 · 九曲溪**：丹霞崖壁、九曲溪、竹筏、玉女峰与茶山。
- **峨眉山 · 金顶**：十方普贤金像、金顶殿宇、云海、古木与猴群。

## 交互

每个场景均提供：

- **地标索引**：左侧「景点」按钮打开，点击条目自动前往。
- **探索印章**：每到一个地标盖一枚印章，进度保存在本地。
- **场景标记**：点击投影标记查看地标卡片与介绍。
- **自动巡游**：按顺序游览各地标，可暂停/继续。
- **天气**：晴 / 雨 / 雪 切换。
- **摄影模式**：隐藏界面，仅保留场景与退出提示。
- **环境音**：程序化风声、水声与鸟鸣，默认关闭。
- **自动光影**：每 12 秒在日间/黄昏之间切换。
- **留影**：下载当前画面为 PNG。
- **第一人称漫游**：`WASD` 移动 · `Space` 跳跃 · 鼠标环顾 · `Shift` 加速 · `Esc` 退出。
- **快捷键**：`1–9` 切换视角 · `F` 第一人称 · `R` 环绕 · `N` 黄昏 · `T` 巡游 · `L` 自动光影 · `O` 总览 · `G` 留影 · `P` 摄影 · `H` 帮助。

## 本地运行

在项目根目录启动任意静态 HTTP 服务：

```bash
python3 -m http.server 8123
```

打开 <http://localhost:8123>。

> 必须通过 HTTP 访问，直接双击 `index.html` 会因 ES Modules 限制而无法加载。

## 技术

- Three.js r160（本地 vendor）
- ES Modules + import map
- 程序化几何、纹理与动态元素
- 共享交互层：`shared/interactions.js`
- 无外部 CDN、无构建依赖
